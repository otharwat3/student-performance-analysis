# Dataset setup

Source: [Kaggle — spscientist/students-performance-in-exams](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams).

1. Open the dataset page and download the data (Kaggle may require sign-in).
2. Extract `StudentsPerformance.csv` from the download.
3. Rename it to `student_performance.csv` and place it in this folder.
4. From the project root, open `notebooks/student_performance_eda.ipynb` and run all cells in order.

The CSV is excluded from Git. Refer to the Kaggle page for the dataset license and usage terms; this repository does not grant a separate data license. Results can change when Kaggle updates the dataset.
